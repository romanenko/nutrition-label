Clean-looking pages can now earn a positive **A** grade. Previously, autoplay and infinite scroll stayed unknown even on pages with no videos or feeds, leaving those sites ungraded.

- A readable scan with no harmful categories detected receives A without requiring Jev.
- Untested behavior or embedded content keeps the grade **provisional**, and unknown criteria remain hidden.
- Empty, loading, failed or truncated scans without usable evidence stay ungraded.
- Newly observed harmful behavior lowers the grade; stopping controls do not cancel detected harms.
- The README now includes a positive A label alongside D and F examples.

Download **nutrition-label-chrome.zip**, extract it and load the **nutrition-label** folder at `chrome://extensions` using **Developer mode → Load unpacked**. For an existing installation, replace the files inside the same folder, click **Reload**, and refresh website tabs. Session-only Jev keys need to be entered again after reloading.

The ZIP includes `INSTALL.txt` and dependency notices. Local detection requires no API key or development server. The accompanying SHA-256 file verifies the archive.

Validation: all 30 automated tests pass. Browser checks cover a clean page receiving A, an empty page remaining ungraded, and provisional A grades on both user-reported sites, Imbue and michael.romanenko.kg, with Jev disabled. Remaining coverage gaps stay visible in Inspection details.

The idea and grading approach are based on [Vlada Bortnik's nutrition-label proposal](https://www.linkedin.com/pulse/weve-been-talking-big-techs-tobacco-moment-years-lets-vlada-jpt2c). Grades describe the observed sample and remain experimental.
