The first downloadable preview of Nutrition Label: a Chrome extension that inspects website attention patterns and presents a food-label-style breakdown.

## Download and install

Download **nutrition-label-chrome.zip** from the assets below. You do not need Node.js, a development server or an API key for local detection. GitHub's **Source code** archives are for developers; use the named extension ZIP to install.

1. Extract the ZIP and keep the files in a permanent location.
2. Enter `chrome://extensions` in Chrome's address bar and enable **Developer mode**.
3. Click **Load unpacked** and select the extracted **nutrition-label** folder containing `manifest.json`.
4. Pin the extension in Chrome's puzzle-piece menu, visit a website and click its icon.

Use Chrome 120 or newer on desktop. `INSTALL.txt` is included in the ZIP and is also attached separately. The SHA-256 file lets you verify the downloaded archive. Updates are manual through Load unpacked/Reload; this preview is not published in the Chrome Web Store.

## Included

- Local observations for feeds, infinite scroll, reactions/ratings, autoplay and attention-related wording.
- Optional Jev classification with your own key, session storage or passphrase-encrypted storage, and a separate feed-text opt-in.
- Distinct-page serving size, numeric per-page averages, and an estimated A–F grade with category contributions. Unknown criteria are hidden.
- Notification detection includes unread Activity/Notifications badges, fixing a missed category on TikTok. Details distinguish these visible cues from verified push notifications or repeated delivery.

The ZIP contains no API key, browsing data, development server or test fixture. Grading and detection remain experimental; visible labels are proxies for broader design choices. All 24 automated tests pass, and the extracted package was checked in Chrome.
